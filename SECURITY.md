# Security Policy

## Supported versions

clawshell is a single-maintainer project. Only the latest released version receives security fixes. Older versions are not patched; update to the latest release instead.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

The automatic updater installs new releases, so most people already run the latest version.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues, discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting:

**[Report a vulnerability](https://github.com/mehdikhody/clawshell/security/advisories/new)**

Include as much of the following as you can:

- The clawshell version (shown in the app and in `package.json`) and your Windows version
- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Any suggested fix or mitigation, if you have one

Please keep the details private until a fix is released or we agree on a disclosure date.

## What to expect

This is an open-source project maintained in spare time, so these are targets rather than guarantees:

- **Acknowledgement:** within 7 days of your report.
- **Assessment:** we will confirm whether the issue is valid and how severe it is, and keep you updated.
- **Fix:** critical and high-severity issues are prioritized for the next release. Lower-severity issues may wait for a regular release.
- **Credit:** we will credit you in the release notes and the advisory, unless you prefer to stay anonymous.

## Scope

In scope:

- The clawshell app and its source code in this repository
- How clawshell reads, stores and uses Claude account tokens and profile data
- The auto-updater, including update signature verification and the release pipeline in this repository
- Isolation between account profiles created by clawshell

Out of scope:

- Claude Desktop, Anthropic's services and endpoints, and the accounts themselves. Report those to Anthropic through its own channels.
- The LiteLLM price list and GitHub, which clawshell only reads from
- Issues that need an attacker who already has local access to your Windows user account, unless clawshell makes that access worse than the platform already does
- Missing hardening with no demonstrated impact
- Reports generated by automated scanners with no analysis or proof of exploitability
- Social engineering, phishing, or denial of service against the maintainer or GitHub

## Handling secrets

clawshell reads each account's OAuth token from its profile folder and keeps it in memory only. Never include real tokens, cookies, or profile contents in a report. Describe the problem, and we will ask for more if we need it.

## Safe harbor

We will not take legal action against you for good-faith security research that follows this policy. That means you avoid privacy violations, data destruction and service disruption, and you give us a reasonable chance to fix the issue before you disclose it publicly.
